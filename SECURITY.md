# Security Policy

## Lab & Educational Use Notice
SOC-Lite is designed for educational, lab, and defense validation purposes. It should be deployed in controlled environments to monitor Windows hosts, validate audit logging policies, and observe detection rules in real-time.

## Supported Versions
Only the latest release branch of SOC-Lite receives security updates.

## Reporting a Vulnerability
If you discover a security vulnerability in SOC-Lite, please open a private GitHub security advisory or contact the maintainers directly. Do not open public issues for zero-day vulnerabilities.
